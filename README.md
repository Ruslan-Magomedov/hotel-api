# Hotel API

Backend-приложение на базе FastAPI для автоматизации бронирования отелей и управления номерами. Проект находится в процессе разработки.

## 🚀 Технологический стек
* **Python 3.10+**
* **FastAPI** — асинхронный веб-фреймворк для создания высокопроизводительных API.
* **Uvicorn** — ASGI-сервер для запуска приложения.
* **SQLAlchemy** — современная ORM для гибкой работы с базой данных.
* **Alembic** — инструмент для генерации и управления миграциями.
* **PostgreSQL** — надежная реляционная СУБД для хранения данных.

---

## 🛠️ Инструкция по установке и запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd hotel-api
```

### 2. Настройка виртуального окружения
Создайте и активируйте виртуальное окружение:

* **Для Linux / macOS:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```
* **Для Windows:**
  ```bash
  python -m venv venv
  venv\Scripts\activate
  ```

### 3. Установка зависимостей
Установите библиотеки, необходимые для работы приложения:
```bash
pip install -r requirements.txt
```

### 4. Конфигурация окружения
Создайте в корне проекта файл `.env` для подключения к вашей СУБД **PostgreSQL**. Заполните его по следующему шаблону:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=hotel_db_name
DB_USER=postgres
DB_PASS=your_secure_password
```
*(Убедитесь, что база данных с указанным именем уже создана в вашем PostgreSQL)*

### 5. Применение миграций
Создайте все необходимые таблицы в базе данных с помощью Alembic:
```bash
alembic upgrade head
```

### 6. Локальный запуск приложения
Запустите ASGI-сервер Uvicorn в режиме автоперезагрузки (удобно для разработки):
```bash
py app/main.py
uvicorn app.main:app --reload
```
